# Mitsitsy

Mitsitsy ("to save, to be thrifty" in Malagasy) is a Next.js app that helps you save your salary first and spend what is left.

- Next.js, TypeScript, Tailwind CSS, shadcn-style components
- English, French and Malagasy
- Charts (salary split donut, goal projection bars), dark theme based on black
- Data stays in your browser (localStorage)

## Run

    npm install
    npm run dev
